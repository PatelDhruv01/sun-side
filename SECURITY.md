# Security

## What's supported

Only the live site, https://sun-side.pages.dev, and the `main` branch get fixes.

## Reporting a problem

Please report it privately rather than in a public issue: on GitHub, open the repository's
**Security** tab and choose **Report a vulnerability**. Say what you found, how to reproduce it
and what it could affect.

The maintainer aims to reply within a week. Once it's fixed, you can be credited in the
[changelog](CHANGELOG.md) if you'd like.

## Scope

In scope: this site and the code in this repository.

Out of scope: the third-party services it calls (OSRM, Valhalla on FOSSGIS servers, Photon,
Open-Meteo and OpenFreeMap). Please report problems with those to the people who run them.

Sun Side has no server, database or accounts of its own. Your recent trips are kept only in your
own browser.
